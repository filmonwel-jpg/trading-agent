How to read it

  1. Databento live records enter through scripts/databento_live_normalizer.py.
  2. The shared relay fans normalized JSON events to each Java symbol bot.
  3. IBKRTrader forwards bars/quotes/order-flow into PingPongStrategy.
  4. The strategy aggregates 1-second source data into 30-second feature buckets and runs ONNX decisions.
  5. Trade intents go back through IBKRTrader risk gates.
  6. Preferred execution goes through the shared Python IBKR gateway on 127.0.0.1:9910.
  7. IBKR fills/status/position events flow back through the gateway to the Java bot and strategy.
